免責與說明

外接終端＝Native Full-Trust：room_join_request 只申請加入房間，不會改變 host 原有的 sandbox、approval、工具、檔案、shell、network 或 subagent 能力；能力仍由 Codex／Claude Code host 掌管。加入後呼叫 room_wait 才會另行申請待命，這也只控制協作收件，不是能力授權。原生旁路無法攔截。

GUI Managed 子 Agent：由 Orchestratory 啟動，對話唯讀；寫入需另行 Owner Writer 授權。

草稿區：獨立副本、看得到、可退回、有紀錄；不是沙盒。核准併入前 main 不會被修改。
